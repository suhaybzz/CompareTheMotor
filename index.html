How the comparison works

CompareTheMotor uses a weighted rule-based scoring system on the backend. Lower values are better for price, insurance group and CO₂ emissions. Higher values are better for MPG and horsepower. Scores are proportional, so small differences produce small score changes rather than unrealistic jumps.

  • Affordability = price + insurance group
  • Efficiency = MPG + CO₂ emissions
  • Performance = horsepower
  • Overall = weighted score based on buyer priority

Core implemented feature

A user applies optional filters, selects two cars, and the system loads stored vehicle data from SQLite, applies comparison rules on the Flask backend, and returns a structured side-by-side result with an overall recommendation.

Note: plug-in hybrid MPG figures are shown as official test-cycle values, which may differ from real-world driving results.
